グローバルとローカル変数宣言代入.anm2で、グローバル変数g、ローカル変数l、をそれぞれ宣言と初期化をする

明るさエフェクト呼び出しローカル変数l.anm2はとあるオブジェクト(３)に付与することで、別のオブジェクトのスクリプト（１）で宣言と初期化をしたものが、また別のオブジェクト（２，３）で呼び出せるかどうかを検証したもの
