# グローバルとローカル変数宣言代入.anm2
# 明るさエフェクト呼び出しグローバル変数g.anm2
# 明るさエフェクト呼び出しローカル変数l.anm2
この3つのスクリプトはセットで機能する  
グローバル変数のスコープと、ローカル変数のスコープを把握することが目的  
グローバルとローカル変数宣言代入.anm2で、グローバル変数g、ローカル変数l、をそれぞれ宣言と初期化をする  
そして、明るさエフェクト呼び出しグローバル変数g.anm2,明るさエフェクト呼び出しローカル変数l.anm2
を別のオブジェクトに付与し、変数g、変数lを呼び出せるかをテストする目的で作成した  
グローバルとローカル変数宣言代入.anm2はとあるオブジェクト(１)に付与し、  
明るさエフェクト呼び出しグローバル変数g.anm2はとあるオブジェクト(２)に付与し、  
明るさエフェクト呼び出しローカル変数l.anm2はとあるオブジェクト(３)に付与することで、別のオブジェクトのスクリプト（１）で宣言と初期化をしたものが、また別のオブジェクト（２，３）で呼び出せるかどうかを検証したもの
